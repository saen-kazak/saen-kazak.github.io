Classification

  • Classification is a form of supervised learning that attempts to assign labels or categories to given input data points, based on data features.
  • Unlike clustering, which is unsupervised, classification attempts to categorize data into classes by analyzing and learning from known examples.

Classification attempts to answer the following question:

given some data,
where each case in the data has been allocated a class,
can we assign a class to a new unseen, unassigned case?

This is known as supervised learning.

ChatGPT Expanded

Classification is used in a wide range of applications, including spam detection, sentiment analysis, medical diagnosis, object recognition, and more. It's a powerful tool for making sense of data and automating decision-making processes.

Training for Classification

  • Classification involves a training phase, unlike clustering.
  • The training phase will allow the classifier to learn the differences between different classes, through analysis of training examples.
  • Once training is complete, the classifier is ready to categorize new examples.

Decision Trees

ChatGPT Explanation

Imagine you have a dataset with various attributes and corresponding labels. Decision trees mimic the way humans make decisions by creating a tree-like structure of decisions based on the features of the data. Each internal node of the tree represents a decision based on an attribute, each branch represents the outcome of that decision, and each leaf node represents the final decision (or class label).

Decision trees are a popular method for displaying the choices made by a classifier, where nodes on the tree represent decisions and arcs represent possible answers. Terminal nodes are reached when the case has been successfully classified.

from kdnugets.com

The goal of using a Decision Tree is to create a training model that can use to predict the class or value of the target variable by learning simple decision rules inferred from prior data(training data).

In Decision Trees, for predicting a class label for a record we start from the root of the tree. We compare the values of the root attribute with the record’s attribute. On the basis of comparison, we follow the branch corresponding to that value and jump to the next node.

Decision trees classify the examples by sorting them down the tree from the root to some leaf/terminal node, with the leaf/terminal node providing the classification of the example.

Each node in the tree acts as a test case for some attribute, and each edge descending from the node corresponds to the possible answers to the test case. This process is recursive in nature and is repeated for every subtree rooted at the new node.

Classifying with a Decision Tree

  • Start at the root node and begin to traverse the tree
  • At each decision node follow the branch most suited to the case being classified
  • Repeat until a terminal node is reached, at which point classification can be done.

Building Decision Trees

  • The creation of decision trees is known as rule induction.
  • To start with, an initial decision point is selected to be the root node.
  • Once the initial node is selected, the data will be split according to the values of the specified attribute.
  • This is repeated until elements belong to a single class and cannot be split further.
  • Nodes then become terminal nodes signifying the creation of a class.
  • The algorithm used to classify determine which nodes to split next, as well as the evaluation function used for splitting.

ID3 Algorithm

ID3 is a classic decision tree algorithm.

Initialization
ID3 begins by creating a root node for the tree.

Stopping Criteria

  • Checks are made to see if all examples being currently examined have the same class label.
  • This represents a situation where no further splitting is needed.
  • If this is the case, a terminal (leaf) node is created with that class label.
  • If there are no attributes left for splitting data, a leaf node is created with the majority class label and this is returned as a decision tree.

Selecting Attributes
ID3 selects the best attribute to split the data based on a criterion called information gain. The attribute with the highest information gain is chosen as the decision attribute for the current node.

Recursion
ID3 will recursively call itself on each subset it creates, allowing for the tree structure creation.

Entropy & Information Gain in Machine Learning

Explained by ChatGPT:

In machine learning, entropy is used to measure the uncertainty or randomness of a dataset. It quantifies how much information is needed to describe the dataset. A dataset with high entropy means it's very unpredictable, while a dataset with low entropy is more organized and predictable.

Information Gain is like a measure of how much a feature (or attribute) helps us to reduce uncertainty or entropy in a dataset. In the context of decision trees, when we're deciding which feature to split on, we want to choose the one that gives us the most information about the class labels of the data points.

So, when we calculate information gain for each feature, we're essentially asking:

"If we split the dataset based on this feature, how much more organized and predictable will the resulting subsets be compared to before the split?"

The feature with the highest information gain is considered the best choice for splitting the dataset because it helps us to gain the most information about the class labels.

In summary, entropy measures the uncertainty or randomness of a dataset, while information gain measures how much a feature helps us to reduce that uncertainty. By selecting features with high information gain, we can build decision trees that effectively classify our data.

Pruning Decision Trees

Occam's Razor

  • A scientific principle dictating that, among competing hypotheses, the one with fewest assumptions should be selected.
  • Within Machine Learning, this translates to simpler models being preferred over more complex ones where everything else is equal.

Overfitting

  • Overfitting is when a classifier becoming too accustomed to the training data.
  • This can include a model capturing noise or random fluctuations in the data instead of the underlying patterns.
  • This causes the model to perform well on classifying training data, but poorly on new unseen data.
  • Decision trees are particularly prone to overfitting, especially those that are overly complex.

Tree pruning is a simplification technique used on decision trees to prevent overfitting.

Much like real trees, it involves removing branches or other parts that do not contribute significantly to the decision making process.

Pruning Process

  • Each decision node is iterated through.
  • Consideration is made to convert the decision node into a terminal/leaf node.
  • The pruning is carried out if classification accuracy is not reduced through this process.
ChatGPT Expanded : Pruning Process
  1. Node Evaluation: Pruning begins by evaluating each decision node in the tree to determine whether converting it into a leaf node (i.e., removing its children and turning it into a terminal node) would improve the overall performance of the tree.
  2. Evaluation Criterion: The decision to prune a node is based on whether doing so reduces the classification accuracy of the tree. This is typically assessed using a validation set or cross-validation, where the pruned tree's performance is compared to the original tree on data not used for training.
  3. Impact on Accuracy: If removing a decision node and converting it into a leaf node does not significantly reduce the classification accuracy of the tree on the validation set, then the pruning is carried out. This simplifies the tree without sacrificing predictive performance.
  4. Iterative Process: Pruning is often performed iteratively, going through each decision node in the tree and evaluating whether pruning it would improve the tree's performance. This process continues until further pruning no longer improves the tree's accuracy or until a predefined stopping criterion is met.

K-Nearest Neighbour

  • K-Nearest Neighbour (KNN) is an algorithm used for classification and regression tasks.
  • It works by classifying new points based on the labels of points closest to them, hence 'nearest neighbour'.
  • KNN uses case based reasoning based on the idea that items located near a new item will influence how unknown data is classified.
  • KNN has been around since 1910.

KNN Requirements

  • Distance Metric: To calculate the distance between 'neighbour' points and the new data.
  • value: The number of neighbours to evaluate.
  • Weighting Function
  • Instructions on combining information from multiple neighbours

Performance in Testing

  • The aim of KNN is to classify new unseen data
  • A simple error rate can assess how effective the classifiers are (on training data):
    • errorRate = num. errors / num. cases

Error rates will be empirical i.e. based on a sample.

Estimated Error Rates

It is possible to determine the empirical, sample-based error rate, since it is only based on a few test cases.

True Error Rates

It is not possible to know the true error rate without access to an infinite number of test cases.

Training & Testing Sets: The Holdout Method

  • Involves splitting a data set into training data and testing data

  • The training set is used to 'learn' the model on the association between the data and the classes the data is categorised into initially.

  • The test set is used to score the model's accuracy by determining the success rate when this data is classified (against known correct values).

  • The two sets will ideally be independent - if the testing data is inside the training data, results will be skewed.

Resampling

Mitigating Data Bias

  • If the data is small or biased, the train and test data can be 'shuffled'
  • Training and testing data can be randomly selected when model training is instantiated.
  • Train and test data could also be shuffled after a fixed number of iterations to diversify the model's input data.
  • Resampling methods can include cross-validation and bootstrapping.

Cross Validation
Cross validation is considered to be an unbiased estimator of true error.

  • K-Fold cross validation involves randomly splitting the data up into sets of equal size.
  • One of the subsets is removed and the classifier is trained on the remaining subsets.
  • The classifier is then tested on the subset that was removed.
  • The process is repeated until all subsets have been tested on.

Bootstrapping
Bootstrapping involves creating multiple data sets by randomly sampling data points from the original set, with replacement.

  • 'Replacement' means that some data points may be selected multiple times, while others may not be selected at all.
  • Cases not used for the training set are used in the test set.
  • The process is repeated to create multiple bootstrap samples with model performance evaluated each time.
  • Bootstrapping is useful for estimating model performance without the need for additional data.
  • Evaluation on multiple bootstrap samples can reduce the variance in model predictions, increasing classifier stability.
  • In some cases, the performance of the model on bootstrap samples may be worse than its performance on the true test set. This is because bootstrapping involves sampling with replacement, which can lead to including noisy or outlier data points in the training set, resulting in poorer performance.

Other Resampling: Random Forest

  • Random Forest extends the bootstrapping technique by using each bootstrap sample to train a decision tree.
  • A random subset of features at each tree node split is taken and the individual predictions are aggregated to produce the final prediction.

Confusion Matrices

  • A confusion matrix is a 2D table used to measure predicted results against actual results.
  • Confusion matrices can be used to evaluate false positives and false negatives, which can be highly important for classifiers used in medical research.

Sensitivity and Specificity

Sensitivity is a measure of positive results. It is defined as the number of true positives detected, divided by the total number of class positives. A more sensitive model is less likely to detect positive results incorrectly as false negatives.

Specificity is a measure of negative results. It is defined as the number of true negatives detected, divided by the total number of class negatives. A more specific model is less likely to detect negative results incorrectly as false positives.

Accuracy is a combination of sensitivity and specificity, defined as the number of correct results over the number of detected objects.

Example

A classifier has a high sensitivity as it has a high success rate for detecting people who have developed cancer. However, it has a low specificity since it also classifies lots of non-cancer results incorrectly.

Balanced and Imbalanced Data

  • Sensitivity and Specificity are good measures for balanced data, where there is a similar number of positive and negative results.
  • They are not good metrics for imbalanced data, such as where there are only a few positive cases.

Precision and Recall

Precision is a measure of true positives identified, divided by all detected positive results, both true and false. A precision value of 1 suggests that there were no false positives picked up by the classifier.

Recall is a measure of true positives detected, divided by the sum of true positives and false negative results . A recall value of 1 suggests that there were no false negatives in the results, i.e. every positive was identified by the classifier.

Measurement Curves

  • A curve showing the trade-off between sensitivity and specificity is known as an ROC - Receiver Operating Characteristic curve.
  • A curve showing the trade-off between precision and recall is known as a PR curve.
